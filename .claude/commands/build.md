`docs/02_onepager.md` にそって実装してください。

守ること:

1. **1回の作業で1ステップだけ**進める。全部まとめてやらない
2. 作業を始める前に、「今からどのファイルに何をするか」を3行以内で伝える
3. `CLAUDE.md` の技術ルールに従う
   - 新しいライブラリを追加しない
   - 色・余白は `app/globals.css` の変数を使う（直接 `#ffffff` などを書かない）
   - 頼まれていないファイルを触らない
4. 「今回は作らないもの」に書かれているものには手を出さない。必要だと思ったら**提案だけして止まる**
5. 実装後、`npm run build` 相当のビルドが通るかを確認する。確認できない場合は、その旨をはっきり伝える

作業が終わったら、以下を報告してください:

- 変更したファイルと、それぞれ何をしたか（箇条書き3行以内）
- 画面のどこを見れば変化が分かるか
- まだ残っているステップ
